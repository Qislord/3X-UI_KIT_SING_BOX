Варианты подключения

Выберите подходящий формат для вашей программы:

🧠 Умный профиль (Рекомендуется для Hiddify и Karing): Включает встроенный Cloudflare DNS DoH (1.1.1.1) без утечек провайдеру, прямой доступ к российским сайтам и банкам (Сбер, Госуслуги, Ozon, Кинопоиск работают без VPN на полной скорости вашего интернета), блокировку QUIC для плавного YouTube 4K и автоматический выбор самого быстрого протокола.
Правило Что делает
DoH 1.1.1.1 Шифрует все DNS-запросы через Cloudflare, оператор связи не видит адреса посещаемых сайтов
Обход РФ сайтов Банки, Госуслуги, доставка и маркетплейсы открываются напрямую без замедлений и не требуют выключения VPN
Block UDP 443 Блокирует нестабильный QUIC-трафик для бесперебойного 4K видео на YouTube
Auto URLTest Программа сама выбирает самый быстрый рабочий узел на лету
Идеально для: ⚡ Hiddify (все ОС) 🛡️ Karing 📦 NekoBox
💡 Стандартная подписка (1 клик): Универсальный формат для классических приложений: V2Box (iOS/Mac), v2rayNG (Android), v2rayN (Windows), Happ, Streisand. Автоматически загружает все доступные протоколы и обновляет их при изменении.
Подходит для: 🍏 V2Box 🤖 v2rayNG 🪟 v2rayN ⚡ Happ 🚀 Streisand
🔑 Прямые ссылки каждого подключения: Здесь находятся индивидуальные ссылки протоколов (VLESS REALITY, Hysteria2, AmneziaWG). Вы можете скопировать все ключи сразу одной кнопкой для ручного импорта.
💡 Подключения AmneziaWG (vpn://) открываются через официальное приложение AmneziaVPN на ПК и смартфонах.

📖 Пошаговые инструкции по настройке

Выберите приложение или платформу для подключения:

🚀 Почему Hiddify — лучший выбор: Приложение Hiddify работает на современном ядре Sing-box. При подключении по Умной подписке (вариант №1) всё работает сразу «из коробки»:
  • Не нужно отключать VPN: российские сайты, Госуслуги, банки, Ozon и Кинопоиск работают напрямую без замедлений на полной скорости.
  • Безопасный DNS: все DNS-запросы зашифрованы через Cloudflare DoH (1.1.1.1) без слежки провайдера.
  • Плавный YouTube 4K: автоматический обход замедлений за счет встроенной блокировки QUIC.
  • Единый интерфейс: одинаково простой и удобный на телефонах, планшетах и компьютерах.

Классическое подключение для iPhone / iPad: V2Box (самое простое альтернативное приложение) или Happ. Работает по Универсальной ссылке.
1
Установите V2Box:

Откройте App Store на iPhone и установите бесплатное приложение V2Box:

🍏 Скачать V2Box в App Store
2
Скопируйте ссылку подписки:

Скопируйте Универсальную подписку (вариант №2 выше):

3
Добавьте в V2Box:
  1. Откройте V2Box.
  2. В нижнем меню перейдите во вкладку Configs.
  3. В правом верхнем углу нажмите «+» → Add Subscription.
  4. Вставьте скопированную ссылку в поле URL и нажмите Save (Сохранить).
  5. Выберите появившийся сервер, перейдите на главный экран Home и включите тумблер. Подтвердите добавление конфигурации в iOS. Готово!
