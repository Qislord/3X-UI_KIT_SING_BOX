📖 Пошаговые инструкции по настройке

Выберите ваше устройство или Sing-box для подробного руководства:

Особенности настройки Sing-box: Sing-box подключается по специальной ссылке (вкладка «2. Sing-Box профиль» выше). Ниже детальные шаги для каждой операционной системы.

🍏 Настройка Sing-box на iPhone / iPad (iOS):

1
Установите приложение Sing-box:

Откройте App Store и найдите sing-box (разработчик SFI / nekohasekai) или перейдите по ссылке:

🍏 Скачать sing-box в App Store
2
Скопируйте ссылку на профиль:

Нажмите кнопку ниже, чтобы скопировать ссылку умного профиля Sing-box в буфер обмена:

3
Добавьте профиль в приложении:
  1. Откройте приложение sing-box на iPhone.
  2. В нижнем меню перейдите во вкладку Profiles (Профили).
  3. Нажмите кнопку New Profile (Новый профиль) или «+».
  4. В поле Name напишите любое имя (например: Мой VPN).
  5. В поле Type обязательно выберите Remote (Удаленный).
  6. В поле URL вставьте скопированную ссылку (или нажмите иконку QR и отсканируйте код).
  7. В строке Auto Update установите 1440 (обновление раз в сутки).
  8. В правом верхнем углу нажмите Create / Save.
4
Запуск:

Поставьте галочку напротив созданного профиля. Перейдите на вкладку Dashboard и включите переключатель Enabled. При первом включении iOS спросит разрешение на добавление конфигурации VPN — нажмите «Разрешить». Готово!

🤖 sing-box в Google Play GitHub Releases (APK)

  1. Скопируйте ссылку профиля кнопкой:
